# Analyzer Fix Notes

This revision addresses the analyzer output reported on 3 October 2026.

## Compile errors fixed

- Pinned `google_fonts` to `8.2.1` to avoid the `9.0.0` `material_ui` TextTheme incompatibility with the existing Flutter Material theme code.
- Imported `CupertinoPageTransitionsBuilder` from `package:flutter/cupertino.dart`.
- Replaced the stale generated `MyApp` counter widget test with a TicketHub theme smoke test.

## Lints/deprecations fixed

- Replaced duplicate unused callback names (`__`, `___`) with Dart wildcard `_` parameters.
- Migrated payment method selection from deprecated `RadioListTile.groupValue/onChanged` to `RadioGroup<String>`.
- Replaced deprecated `ButtonBar` with `OverflowBar`.
- Replaced nullable collection `if` with the Dart null-aware element (`?action`).
- Guarded asynchronous `BuildContext` usage with `context.mounted` in admin business status updates.
- Added braces to the category upsert `if/else` branch.

## Before analyzing

Run these commands from the project root:

```powershell
flutter clean
flutter pub get
flutter analyze
flutter test
```

`flutter pub get` is important because the dependency pin changed from `google_fonts 9.0.0` to `8.2.1`.
pubspec.lock will be regenerated by flutter pub get because google_fonts was repinned.
