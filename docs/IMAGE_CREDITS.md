# Event image credits

TicketHub demo imagery uses photographs hosted by Wikimedia Commons. The Flutter UI loads these images from their Commons `Special:FilePath` URLs; the included `scripts/download_event_images.ps1` helper can also save copies into `assets/images/online/` for local development.

- Concert crowd / live event: Wikimedia Commons — “A large crowd enjoys a music concert illuminated by colorful lights and a stunning stage display.jpg” (CC BY 2.0; photographer/author credited on the Commons file page).
- Cinema screen: Wikimedia Commons — “Cinema theatre screen.jpg”.
- Theatre performance: Wikimedia Commons — “Theatre performance.jpg”.
- Sports stadium: Wikimedia Commons — “Spectators in a sports stadium observing a football match1.jpg”.
- Workshop/coding: Wikimedia Commons — “Wiki Hackathon 2026 India - Coding Session - IMG190.jpg”.
